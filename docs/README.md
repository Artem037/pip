# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = a * h / 2

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c


# Описание фукнций:

# Circle

- ## `area(r)`:
### Возвращает площадь круга с радиусом длины `r`.

``` 
Параметры:
    r (float): длина радиуса круга

Возвращаемое значение:
    math.pi * r * r (float): площадь круга
 ```

```
s = area(4)
print(s)
```
### Вывод:
`50.26548245743669`

- ## `perimeter(r)`:
### Возвращает длину окружности с радиусом длины `r`.

```
Параметры:
    r (float): длина радиуса окружности

Возвращаемое значение:
    2 * math.pi * r (float): длина окружности (периметр)
```

```
p = perimeter(4)
print(p)
```
### Вывод:
`25.132741228718345`

# Rectangle

- ## `area(a, b)`:
### Возвращает площадь прямоугольника со сторонами длины `a` и `b`.

```
Параметры:
    a (float): сторона прямоугольника
    b (float): сторона прямоугольника, прилежащая к стороне а 

Возвращаемое значение:
    a * b (float): площадь прямоугольника
```

```
s = area(3, 7)
print(s)
```
### Вывод:
`21`

- ## `perimeter(a, b)`:
### Возвращает периметр прямоугольника со сторонами длины `a` и `b`.
```
Параметры:
    a (float): сторона прямоугольника
    b (float): сторона прямоугольника, прилежащая к стороне а 

Возвращаемое значение:
    a * 2 + b * 2 (float): периметр прямоугольника
```

```
p = perimeter(3, 7)
print(p)
```
### Вывод:
`20`

# Square

- ## `area(a)`:
### Возвращает площадь квадрата со стороной длины `a`.
```
Параметры:
   a (float): длина стороны квадрата

Возвращаемое значение:
    a * a (float): площадь квадрата
```

```
s = area(12)
print(s)
```
### Вывод:
`144`

- ## `perimeter(a)`:
### Возвращает периметр квадрата со стороной длины `a`.
```
Параметры:
    a (float): длина стороны квадрата

Возвращаемое значение:
    4 * a (float): периметр квадрата
```

```
p = perimeter(12)
print(p)
```
### Вывод:
`48`

# Triangle

- ## `area(a, h)`:
### Возвращает площадь треугольника со стороной длины `a` и высотой, проведенной к этой стороне, длины `h`.
```
Параметры:
    a (float): длина стороны треугольника
    h (float): длина высоты, проведенной к этой стороне

Возвращаемое значение:
    a * h / 2 (float): площадь треугольника
```

```
s = area(7, 5)
print(s)
```
### Вывод:
`17.5`

- ## `perimeter(a, b, c)`:
### Возвращает периметр треугольника со сторонами длины `a`, `b` и `c`.

```
Параметры:
    a (float): длина первой стороны треугольника
    b (float): длина второй стороны треугольника
    с (float): длина третьей стороны треугольника

Возвращаемое значение:
    a + b + c (float): периметр треугольника
```

```
p = perimeter(5, 9, 2)
print(p)
```
### Вывод:
`16`
